# MovieFinder

A movie search website. Type in a movie name and it shows matching results from the OMDb movie database.

**Live site:** https://s00254071.github.io/MovieFinder/

## Features

- Search any movie by title
- Results show the title, year and IMDb ID
- Pages to move through the results
- Click a movie to see its poster and details
- Error message if a movie can't be found

## Built with

Angular, TypeScript, Bootstrap, OMDb API
